INSTALLATION POWERSHELL
-----------------------

1. Fermer l'application GeoPoint si elle tourne.

2. Extraire l'archive cumulative :

Expand-Archive "$env:USERPROFILE\Downloads\geopoint_point_27_etape_11_validation_finale.zip" "D:\romai\GEOPOINT\geopoint" -Force

3. Ouvrir le projet :

cd D:\romai\GEOPOINT\geopoint

4. Vérifier le code :

flutter analyze

5. Lancer les 170 tests :

flutter test

6. Lancer sur le Pixel 10 :

flutter run -d 58041FDCR00681

VALIDATION FINALE DU POINT 27
-----------------------------

1. Ouvrir Paramètres > Outils XP de développement.
2. Remettre l'XP à 0 et vérifier Premiers pas I, 0 XP.
3. Vérifier dans le Passeport que le prochain objectif reste visible et que la
   carte GeoBrain conserve les connaissances existantes.
4. Utiliser À 1 XP du prochain palier, puis ajouter 1 XP.
5. Vérifier le nouveau palier et l'absence de fenêtre forcée.
6. Remettre l'XP à 0, puis utiliser Préparer le grand niveau.
7. Vérifier 399 XP et Premiers pas IV.
8. Jouer une partie normale valide.
9. Vérifier la célébration Curieux du monde, les récompenses et le prochain
   objectif.
10. Désactiver Animation de grand niveau dans Paramètres et répéter un passage :
    le contenu doit rester visible sans mouvement.
11. Utiliser Atteindre le niveau maximal.
12. Vérifier Maître du monde IV, la barre terminée et l'absence de faux niveau
    suivant.
13. Remettre finalement l'XP à 0 pour reprendre l'expérience normalement.
14. Vérifier que les parties, statistiques, tampons, Atlas et GeoBrain n'ont pas
    été effacés.
