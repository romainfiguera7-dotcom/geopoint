POINTGEO V1 — INFORMATIONS LÉGALES ET CONFIDENTIALITÉ
====================================================

Cette version prépare PointGeo pour un public de 16 ans et plus.

INSTALLATION
------------

Dans PowerShell :

cd D:\romai\GEOPOINT\geopoint
.\android\gradlew.bat --stop

cd D:\romai\GEOPOINT
$copieImbriquee = "D:\romai\GEOPOINT\geopoint\geopoint"
if (Test-Path "$copieImbriquee\pubspec.yaml") {
    Remove-Item $copieImbriquee -Recurse -Force -ErrorAction Stop
}

Expand-Archive "$env:USERPROFILE\Downloads\pointgeo_legal_confidentialite_v1.zip" "D:\romai\GEOPOINT" -Force

# Si la suppression de la copie imbriquée est refusée, fermer Android Studio
# et les fenêtres ouvertes dans ce dossier, puis relancer ces commandes.

cd D:\romai\GEOPOINT\geopoint
flutter pub get
flutter analyze
flutter test
npm --prefix functions run check

ADMOB — À FAIRE APRÈS LA CRÉATION DE L’APPLICATION
--------------------------------------------------

Les identifiants publicitaires actuels sont les identifiants de test officiels
de Google. Avant une version publique :

1. Créer l’application PointGeo dans AdMob.
2. Créer une annonce interstitielle.
3. Créer et publier un message RGPD dans Confidentialité et messages.
4. Remplacer uniquement les identifiants de test AdMob par ceux de PointGeo.
5. Tester le formulaire de consentement et une publicité depuis une piste de
   test Google Play avant la production.

CE QUI EST INTÉGRÉ DANS L’APPLICATION
-------------------------------------

- Mentions légales, politique de confidentialité et conditions d’utilisation.
- Confirmation « 16 ans ou plus » avant la création/association d’un compte.
- Gestion du consentement Google AdMob avant toute demande publicitaire.
- Accès permanent aux choix publicitaires depuis les Paramètres.
- Suppression du compte dans Paramètres > Mon compte.
- Effacement Firebase des données du profil, portefeuille, progression,
  défis, classements, amis et éléments publics associés.
- Page web externe de demande de suppression pour Google Play.

Les identifiants techniques existants (package Android, projet Firebase,
dossiers et classes GeoPoint) restent inchangés afin de ne pas casser la V1.
